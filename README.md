# Електронний деканат: облік студентів навчального закладу

## Опис проєкту

Даний проєкт є курсовою роботою з дисципліни «Інженерія програмного забезпечення».

Метою роботи є розробка інформаційної системи електронного деканату для автоматизації обліку студентів навчального закладу.

Система дозволяє:
- додавати студентів;
- редагувати інформацію про студентів;
- видаляти студентів;
- створювати академічні групи;
- виконувати пошук інформації;
- вести облік проживання у гуртожитку;
- працювати з базою даних SQLite.
